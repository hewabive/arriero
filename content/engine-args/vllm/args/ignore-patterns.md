# --ignore-patterns

## Кратко

Аргумент передается в `huggingface_hub.snapshot_download(ignore_patterns=...)` при скачивании весов. Его единственная задача — не тащить лишние гигабайты: у репозиториев Llama рядом с шардированными safetensors лежит каталог `original/` с тем же чекпоинтом в другом формате, и без фильтра он скачивается вторым экземпляром.

Ключевая ловушка: `nargs="+"` означает **замену** списка, а не добавление. Указав `--ignore-patterns "*.pth"`, вы снимаете дефолтный `original/**/*` и рискуете удвоить объем загрузки.

## Оригинальная справка

```text
The list of patterns to ignore when loading the model. Default to
"original/**/*" to avoid repeated loading of llama's checkpoints.
```

## Паспорт аргумента

- Флаги: `--ignore-patterns`
- Группа argparse: `LoadConfig`
- Тип значения: список строк (`nargs="+"`, элемент — `str`); поле объявлено как `list[str] | str`
- Допустимые значения: не ограничены; синтаксис — glob-шаблоны `fnmatch`, как их понимает `huggingface_hub`
- Значение по умолчанию: `Field(default_factory=lambda: ['original/**/*'])`, то есть список из одного шаблона `original/**/*`
- Эффективное значение: не переопределяется. Валидатор `_validate_ignore_patterns` только логирует факт отличия от дефолта
- Где объявлен: `vllm/config/load.py:LoadConfig.ignore_patterns`
- Этап применения: подготовка весов (`_prepare_weights`), до загрузки модели; только для нелокальных моделей

## Что меняет в движке

Единственная точка использования — `DefaultModelLoader._prepare_weights`:

```
if not is_local:
    hf_folder = download_weights_from_hf(
        model_name_or_path, self.load_config.download_dir, allow_patterns,
        revision, subfolder=subfolder, ignore_patterns=self.load_config.ignore_patterns)
```

Оттуда значение уходит в `snapshot_download`. Взаимодействие с `allow_patterns` неочевидно: если формат safetensors и в репозитории есть `model.safetensors.index.json`, `download_weights_from_hf` подменяет `allow_patterns` точным списком файлов из индекса — но `ignore_patterns` продолжает применяться поверх. Слишком широкий шаблон способен исключить обязательный шард, и загрузка завершится «успешно» без нужных файлов.

Валидатор поля печатает при непустом и отличном от дефолта значении:

```text
Ignoring the following patterns when downloading weights: <ваш список>
```

Локальную модель аргумент не затрагивает: при `os.path.isdir(model)` файлы просто перечисляются `glob`-ом по каталогу без всякой фильтрации, а `RunaiModelStreamerLoader`, `ShardedStateLoader` и `TensorizerLoader` его не читают вовсе.

## Значения и формат

- Один или несколько шаблонов через пробел: `--ignore-patterns "original/**/*" "*.pth"`. Кавычки обязательны, иначе шаблон раскроет shell.
- Список **заменяет** дефолт целиком. Чтобы добавить свой шаблон и сохранить исходный, перечислите оба.
- Пустое значение задать нельзя: `nargs="+"` требует минимум один аргумент. Практический способ «отключить фильтрацию» — указать заведомо несуществующий шаблон, но тогда репозитории Llama будут скачиваться дважды.
- Шаблоны сопоставляются с путями относительно корня репозитория, включая подкаталоги.
- Валидатор логирует список только если он не равен ровно `['original/**/*']` и не пуст.

## Когда использовать

- Репозиторий содержит альтернативные форматы весов, которые вам не нужны: `original/`, `*.pth`, `*.gguf`, `*-fp8/`. Экономия на большой модели измеряется десятками гигабайт и минутами старта.
- Репозиторий содержит файлы, которые не должны попадать на хост по политике (демо-данные, изображения, ноутбуки).
- Не используйте для выбора формата весов — для этого есть `--load-format`, который задает `allow_patterns`. Фильтр исключений применяется поверх и легко исключает нужное.
- Не используйте на локальной модели: аргумент не читается.

## Влияние на производительность и память

- **Время холодного старта.** Основной эффект: меньше скачивается — быстрее первый старт.
- **Диск.** Прямо определяет объем кэша загрузки.
- **VRAM и RAM.** Не влияет: фильтруется только загрузка, а не то, что грузится в память.
- **Теплый старт.** Не влияет: при заполненном кэше загрузка не выполняется.

## Взаимодействие с другими аргументами

- `--load-format`: определяет `allow_patterns` (что разрешено скачивать), этот аргумент — что исключено из разрешенного. Конфликт разрешается в пользу исключения.
- `--download-dir`: каталог, куда идет отфильтрованная загрузка.
- `--model`: аргумент работает только когда модель задана repo id.
- `--revision`: фильтрация применяется к содержимому конкретной ревизии.
- `--hf-token`: не связаны, но обе проблемы (нет доступа / скачалось не то) проявляются в одном месте — на этапе `_prepare_weights`.

## Типовые проблемы и диагностика

- **Симптом:** `Cannot find any model weights with <model>` после задания своего списка. **Причина:** шаблон исключил все файлы, подходящие под `allow_patterns`. **Лечение:** сузить шаблон; проверить, какие файлы реально есть в репозитории.
- **Симптом:** модель грузится, но часть весов не инициализирована — `Following weights were not initialized from checkpoint: {...}`. **Причина:** исключен один из шардов safetensors. **Лечение:** убрать шаблон, задевающий `model-*-of-*.safetensors`.
- **Симптом:** объем загрузки вдвое больше ожидаемого. **Причина:** свой список вытеснил дефолтный `original/**/*`. **Лечение:** перечислить оба шаблона.
- **Симптом:** список задан, в логе нет строки об игнорировании. **Причина:** значение совпало с дефолтом либо модель локальная и загрузка не выполнялась. **Проверка:** строка `Ignoring the following patterns when downloading weights: ...` при старте.

## Примеры

```bash
vllm serve meta-llama/Llama-3.1-8B-Instruct --ignore-patterns "original/**/*"
```

```bash
vllm serve meta-llama/Llama-3.1-8B-Instruct --ignore-patterns "original/**/*" "*.pth" --download-dir /data/hf-cache
```
