# --kda-decode-backend

## Кратко

Выбирает backend KDA для decode-фазы.

## Оригинальная справка

```text
Select KDA decode backend.
```

## Паспорт аргумента

- Флаги: `--kda-decode-backend`
- Группа argparse: не указана
- Тип значения: определяется парсером установленной версии
- Значение по умолчанию в декларации: `None`
- Где объявлен: `vllm/engine/arg_utils.py:add_cli_args`

## Что меняет в движке

Флаг разбирается в EngineArgs; выбранный backend должен поддерживаться платформой и моделью.

## Значения и формат

Допустимые значения и ограничения проверяются при разборе CLI и построении конфига.

## Когда использовать

Задавайте после сравнения latency KDA decode на своей системе; без флага выбор остаётся за движком.

## Влияние на производительность и память

Ядра backend различаются скоростью и рабочей памятью; универсального лучшего значения нет.

## Взаимодействие с другими аргументами

Применяется вместе с настройками того же компонента; проверяйте итоговый конфиг при запуске.

## Типовые проблемы и диагностика

Если backend недоступен, проверьте точный список в vllm serve --help установленной версии.

## Примеры

```bash
vllm serve /models/model --kda-decode-backend auto
```
