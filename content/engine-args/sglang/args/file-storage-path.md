# --file-storage-path

## Кратко

`--file-storage-path` — мертвый аргумент. Поле `ServerArgs.file_storage_path` объявлено и попадает в namespace, но **ни одна строка кода в `python/sglang/` его не читает**. Каталог с именем `sglang_storage` не создается, файлы туда не пишутся, ошибок при несуществующем пути не бывает.

Исторически значение использовал обработчик загрузки файлов OpenAI-совместимого Files/Batch API (`upload_file`, `storage_dir`), который был удален вместе со всем старым модулем `openai_api` при переходе на `entrypoints/openai` (upstream PR #7351, июнь 2025). Аргумент и запись в справочной таблице документации остались, потребитель — нет.

## Оригинальная справка

```text
The path of the file storage in backend.
```

## Паспорт аргумента

- Флаги: `--file-storage-path`
- Группа: `serving`
- Тип значения: str (путь)
- Допустимые значения: не ограничены; проверок нет
- Значение по умолчанию: `"sglang_storage"` — относительный путь, который никогда никуда не разрешается
- Эффективное значение: совпадает с заданным; `__post_init__` поле не трогает. Никакого «эффективного поведения» у него нет вовсе
- Где объявлен: `ServerArgs.file_storage_path`, файл — `sglang/python/sglang/srt/server_args.py`
- Статус: формально обычный (не `hidden`, не `Deprecated*Action`), фактически — не подключенный ни к чему остаток. В `--help` он показывается, что и делает его источником ложных ожиданий
- Этап применения: отсутствует. Значение доходит до датакласса и на этом останавливается

## Что меняет в движке

Ничего. Проверяется одной командой в checkout'е:

```bash
grep -rn "file_storage_path" python/sglang/
```

Результат — только объявление в `server_args.py`. В `entrypoints/openai/` нет ни маршрута `/v1/files`, ни `/v1/batches`, ни какого-либо кода, который бы обращался к этому пути. История поля (`git log -S"file_storage_path" -- python/sglang/srt/`) заканчивается коммитом `72676cd6c0` «feat(oai refactor): Replace `openai_api` with `entrypoints/openai` (#7351)», который удалил обработчик `upload_file(file, purpose, file_storage_path)` — единственного потребителя.

## Значения и формат

- Любая строка. Существование пути не проверяется, права не проверяются, каталог не создается.
- Значение по умолчанию `sglang_storage` — относительный путь; если бы потребитель существовал, он резолвился бы от рабочего каталога процесса.
- Аргумент невозможно задать «неправильно»: никакая строка не приведет к ошибке и никакая не приведет к эффекту.

## Когда использовать

- Не использовать. Единственная осмысленная причина упомянуть аргумент — объяснить коллеге, почему он есть в `--help` и почему ничего не делает.
- Если вам нужен OpenAI Files/Batch API, его в этой версии SGLang просто нет; проверяется отсутствием маршрутов `/v1/files` и `/v1/batches` в `entrypoints/http_server.py`.

## Влияние на производительность и память

Отсутствует: значение не читается, дискового ввода-вывода не порождает, на VRAM, RAM и время старта не влияет.

## Взаимодействие с другими аргументами

Взаимодействий нет: ни один `_handle_*`, ни одна проверка `check_server_args` и ни один другой аргумент это поле не читают. Не путайте его с `--download-dir` (каталог загрузки весов с Hugging Face) и с `--hicache-storage-backend` (внешнее хранилище префиксного KV-кеша) — вот они действующие.

## Типовые проблемы и диагностика

- **Симптом:** задали путь, каталог не появился. **Причина:** потребителя нет. **Проверка:** `grep -rn "file_storage_path" python/sglang/` в checkout'е установленной версии.
- **Симптом:** ожидали, что заработает `/v1/files`. **Причина:** маршрута нет с июня 2025 года. **Проверка:** `curl -i http://127.0.0.1:30000/v1/files` вернет 404.
- **Подтверждение того, что значение принято argparse:** строка `server_args=` в логе старта покажет `file_storage_path='...'` — но это ровно все, что с ним произойдет.

## В arriero

Аргумент безвреден и бесполезен. Он не входит в список ключей, зарезервированных за типизированной конфигурацией движка (`KTRANSFORMERS_RESERVED_ARG_KEYS` в `packages/core/src/instance.ts`), поэтому схема инстанса его примет и передаст в командную строку. Эффекта не будет никакого; в аргументах инстанса он останется мусором, который потом придется объяснять.

Если в конфигурации арриеро он уже есть — удаляйте, перезапуск не потребует ничего, кроме обычного рестарта инстанса.

## Примеры

```bash
python -m sglang.launch_server --model-path /models/Qwen3-30B-A3B --host 127.0.0.1 --port 30000 --file-storage-path /var/lib/sglang/files
```

```bash
python -m sglang.launch_server --model-path /models/Qwen3-30B-A3B --host 127.0.0.1 --port 30000
```
