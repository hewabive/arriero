# --warmups

## Кратко

`--warmups` запускает именованные функции из реестра `sglang/python/sglang/srt/entrypoints/warmup.py` до того, как сервер начнет принимать соединения. Это отдельный механизм от штатного прогревочного запроса: `--skip-server-warmup` на него не действует, и наоборот.

Реестр закрытый — функция попадает в него только декоратором `@warmup("<имя>")` внутри этого файла. Расширить список аргументами командной строки нельзя, только правкой исходников. На текущем commit'е зарегистрировано три имени: `whisper_autodetect`, `voice_chat`, `prefill_shapes`.

## Оригинальная справка

```text
Specify custom warmup functions (csv) to run before server starts eg. --warmups=warmup_name1,warmup_name2 will run the functions `warmup_name1` and `warmup_name2` specified in warmup.py before the server starts listening for requests
```

## Паспорт аргумента

- Флаги: `--warmups`
- Группа: `serving`
- Тип значения: str — имена через запятую (разбор `server_args.warmups.split(",")`)
- Допустимые значения: `choices` в extract нет, но фактический список закрыт реестром `_warmup_registry`. Способ посмотреть его на своей сборке: `<env>/bin/python -c "import sglang.srt.entrypoints.warmup as w; print(sorted(w._warmup_registry))"`
- Значение по умолчанию: `None` — пользовательские прогревы не выполняются
- Эффективное значение: совпадает с заданным; переписывания нет
- Где объявлен: `ServerArgs.warmups`, файл — `sglang/python/sglang/srt/server_args.py`
- Статус: обычный
- Этап применения: HTTP-слой, внутри `lifespan` приложения — после инициализации глобального состояния и **до** `yield`, то есть до того, как uvicorn/Granian начнет принимать соединения

## Что меняет в движке

`lifespan` в `entrypoints/http_server.py` выполняет:

```python
if server_args.warmups is not None:
    await execute_warmups(
        server_args.disaggregation_mode,
        server_args.warmups.split(","),
        _global_state.tokenizer_manager,
    )
    logger.info("Warmup ended")
```

`execute_warmups` идет по именам последовательно; неизвестное имя дает `logger.warning(f"Could not find custom warmup {warmup_name}")` и пропускается — старт не прерывается. Найденное имя логируется как `Running warmup {warmup_name}` и вызывается с `(disaggregation_mode, tokenizer_manager)`.

Функции обращаются к движку напрямую через `tokenizer_manager.generate_request(...)`, без HTTP. При `disaggregation_mode != "null"` они дополнительно проставляют фиктивные `bootstrap_room = 0` и `bootstrap_host = FAKE_BOOTSTRAP_HOST`, иначе PD-prefill-планировщик отверг бы запрос.

### Что делает каждая зарегистрированная функция

- **`whisper_autodetect`** — компилирует xgrammar-автомат для двух регулярных выражений автоопределения языка Whisper (варианты с временными метками и без). Первый запрос с каждым из этих regex стоит 15–20 секунд компиляции; прогрев переносит эту стоимость на старт. Требует `soundfile` (генерирует 0.1-секундный тихий WAV) и осмыслен только для Whisper-подобных моделей транскрипции.
- **`voice_chat`** — 511 итераций `generate` с `input_ids` длиной `4, 8, …, 2044`, чтобы прогреть Triton-ядра fused MoE. В комментарии сказано прямо: без этого real-time голосовой сценарий ломается. Прогон длинный — это сотни forward-проходов подряд.
- **`prefill_shapes`** — прогрев Triton-ядер по сетке длин prefill до 32K: степени двойки от 64 плюс промежуточные точки, выровненные по 64. Каждая точка — один forward с `max_new_tokens=1`.

Все три показывают прогресс через `tqdm`, поэтому в логах появится характерный прогресс-бар.

## Значения и формат

- Разделитель — запятая, без пробелов: `--warmups voice_chat,prefill_shapes`. Пробел после запятой попадет в имя и приведет к предупреждению «Could not find custom warmup».
- Порядок исполнения — порядок в строке.
- Регистр значим: имена сравниваются точным совпадением ключа словаря.
- Пустая строка `--warmups ""` — не `None`, поэтому `split(",")` даст `[""]`, и вы получите одно предупреждение о ненайденном прогреве. Лучше просто не задавать аргумент.
- Опечатка не является ошибкой конфигурации: сервер стартует, прогрев молча не выполняется. Это главный источник ложной уверенности.

## Когда использовать

- Whisper/транскрипция с автоопределением языка — `whisper_autodetect` снимает 15–20-секундную паузу с первого запроса.
- Голосовой real-time сценарий на MoE-модели — `voice_chat`, ровно ради чего он и написан.
- Нагрузка с широким разбросом длин промпта, где вы не готовы платить компиляцией Triton-ядер по ходу дела, — `prefill_shapes`.
- Не включайте «на всякий случай»: `voice_chat` и `prefill_shapes` заметно удлиняют старт, а на модели, где нужные ядра не используются, не дают ничего.
- Не рассчитывайте прогреть этим механизмом собственный сценарий: реестр закрыт, добавление имени требует правки `warmup.py`, то есть модификации установленного пакета.

## Влияние на производительность и память

- **Время старта — основной эффект.** `prefill_shapes` выполняет около двух десятков forward-проходов вплоть до 32K токенов; `voice_chat` — 511 коротких проходов. На больших моделях это минуты.
- **VRAM.** Прогревы идут через обычный конвейер и занимают KV-пул на время запроса; `prefill_shapes` с длиной 32768 требует, чтобы `--context-length` и размер пула это допускали, иначе прогрев упрется в ограничение и выдаст ошибку в логе.
- **Latency первого клиентского запроса** — падает ровно на стоимость компиляции тех ядер, которые прогрев успел задеть.
- **RAM хоста** — компиляция Triton и xgrammar происходит на CPU, но кеши невелики.

## Взаимодействие с другими аргументами

- `--skip-server-warmup`: независим. Отключает штатный HTTP-запрос к самому себе, но не пользовательские прогревы.
- `--disaggregation-mode`: передается первым аргументом в каждую прогревочную функцию; при значении, отличном от `null`, добавляются фиктивные bootstrap-поля.
- `--page-size`: `prefill_shapes` выравнивает промежуточные размеры по константе 64, зашитой в саму функцию, а не по вашему `--page-size`. При другом размере страницы выравнивание прогревочных длин перестает совпадать с реальным.
- `--enable-multimodal`: `whisper_autodetect` работает только на модели с аудио-входом.
- `--tool-call-parser`: к прогреву отношения не имеет; xgrammar здесь компилируется под регулярные выражения Whisper, а не под грамматику инструментов.

## Типовые проблемы и диагностика

- **Симптом:** в логе `Could not find custom warmup <имя>`. **Причины:** опечатка, пробел после запятой, имя из другой версии SGLang. **Проверка:** вывести реестр командой из «Паспорта».
- **Симптом:** старт затянулся на минуты, в логе прогресс-бар `tqdm`. **Причина:** идет `voice_chat` или `prefill_shapes`. **Лечение:** убрать прогрев, если он не нужен.
- **Симптом:** прогрев падает с ошибкой длины контекста. **Причина:** `prefill_shapes` доходит до 32768 токенов, а модель или пул этого не допускают. **Лечение:** не использовать этот прогрев на короткоконтекстных конфигурациях.
- **Симптом:** `whisper_autodetect` падает на импорте. **Причина:** нет пакета `soundfile`. **Проверка:** `<env>/bin/python -c "import soundfile"`.
- **Подтверждение выполнения:** пара строк `Running warmup <имя>` … `Warmup ended` в логе; они появляются до строки о старте прослушивания.

## В arriero

Аргумент передается как обычный ключ в сырых `args` инстанса — в списке зарезервированных за конфигурацией движка его нет. Ограничений со стороны менеджера нет, но есть два эксплуатационных соображения.

1. **Прогрев выполняется до открытия порта**, поэтому все это время HTTP-проба менеджера не получает соединения, а лог-парсер SGLang не увидит ни `Uvicorn running on`, ни `Application startup complete`. Инстанс будет висеть в состоянии загрузки ровно столько, сколько идет прогрев. Для kind `ktransformers` это ощутимо: там и без прогревов старт долгий из-за загрузки CPU-весов экспертов.
2. **Для квалифицированного профиля (`docs/KTRANSFORMERS_OPERATIONS.md`) ни один из трех прогревов не нужен**: профиль текстовый, без Whisper и без голосового real-time. `prefill_shapes` теоретически применим, но его сетка длин выровнена по константе 64 и не учитывает конфигурацию KT-экспертов; выигрыш надо измерять, а не предполагать.

## Примеры

```bash
python -m sglang.launch_server --model-path /models/whisper-large-v3 --host 127.0.0.1 --port 30000 --warmups whisper_autodetect
```

```bash
python -m sglang.launch_server --model-path /models/Qwen3-30B-A3B --host 127.0.0.1 --port 30000 --warmups prefill_shapes --context-length 32768
```
