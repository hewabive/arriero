# --dllm-algorithm-config

## Кратко

Алгоритмы разглаживания имеют собственные гиперпараметры — порог уверенности, порог редактирования, бюджет пост-правок, штраф за повтор. В `ServerArgs` для них нет отдельных полей: все они читаются из одного YAML-файла, путь к которому задает этот аргумент. Тот же файл может переопределить `block_size` — размер блока, который иначе берется из таблицы поддерживаемых архитектур.

Аргумент читается только при заданном `--dllm-algorithm`. Файл открывается на старте несколько раз: конфиг диффузии строится и при резолюции `--page-size`, и при создании объекта алгоритма.

## Оригинальная справка

```text
The diffusion LLM algorithm configurations. Must be a YAML file.
```

## Паспорт аргумента

- Флаги: `--dllm-algorithm-config`
- Группа: `exec.dllm`
- Тип значения: str (`Optional[str]`) — путь к файлу
- Допустимые значения: путь к существующему YAML-файлу; никаких проверок расширения нет, содержимое читается `yaml.safe_load`
- Значение по умолчанию: `null` — алгоритм работает на встроенных значениях
- Эффективное значение: словарь из файла попадает в `DllmConfig.algorithm_config`; ключ `block_size` из него перекрывает значение из таблицы архитектур
- Где объявлен: `ServerArgs.dllm_algorithm_config`, файл — `sglang/python/sglang/srt/server_args.py`
- Статус: обычный
- Этап применения: `__post_init__` (при резолюции `--page-size` через `DllmConfig.from_server_args`) → инициализация scheduler'а (создание алгоритма)

## Что меняет в движке

Файл загружается в `DllmConfig.from_server_args`:

```python
with open(server_args.dllm_algorithm_config, "r") as f:
    algorithm_config = yaml.safe_load(f)
block_size = algorithm_config.get("block_size", block_size)
```

Дальше словарь целиком передается конструктору алгоритма, и каждый алгоритм разбирает свои ключи через `.get(...)` со значением по умолчанию. Незнакомые ключи молча игнорируются — опечатка в имени параметра не приводит ни к ошибке, ни к предупреждению.

Ключи, которые читает checkout:

**Общий**

- `block_size` — переопределяет размер блока архитектуры. Влияет и на `--page-size` (тот приравнивается к размеру блока), и на число шагов разглаживания.

**`LowConfidence`** (`low_confidence.py`)

- `threshold` (по умолчанию `0.95`) — минимальная softmax-уверенность, при которой позиция раскрывается на этом шаге. Если ни одна позиция не проходит порог, раскрывается одна самая уверенная, так что прогресс гарантирован.

**`JointThreshold`** (`joint_threshold.py`)

- `threshold` (по умолчанию `0.5`) — порог раскрытия замаскированных позиций;
- `edit_threshold` (по умолчанию `0`) — порог правки уже раскрытых токенов;
- `max_post_edit_steps` (по умолчанию `16`) — бюджет шагов пост-редактирования после того, как масок не осталось; он же входит в `max_steps` как `block_size + max_post_edit_steps + 1`;
- `penalty_lambda` (по умолчанию `0`) — штраф, вычитаемый из логита токена, совпадающего с предыдущим, — средство против повторов;
- `vectorized_decoding` (по умолчанию — истина на NPU, ложь на остальных платформах) — батчевый путь шага вместо построчного.

Требуется установленный PyYAML: при его отсутствии старт падает с `ImportError: Please install PyYAML to use YAML config files. 'pip install pyyaml'`.

## Значения и формат

- Абсолютный или относительный путь; существование проверяется только моментом открытия — несуществующий файл дает `FileNotFoundError` на старте.
- Содержимое — YAML-отображение верхнего уровня; список или скаляр приведут к `AttributeError` на первом `.get`.
- Пустой файл (`yaml.safe_load` вернет `None`) сломает вызов `.get` — оставьте хотя бы `{}`.
- Это **не** тот же файл, что `--config`: последний задает значения аргументов сервера, а этот — параметры алгоритма разглаживания. Их структуры несовместимы.
- Без `--dllm-algorithm` значение не читается.

## Когда использовать

- Когда встроенный порог `LowConfidence` (0.95) слишком консервативен и блок разглаживается почти по одному токену за шаг — снижение порога раскрывает больше позиций за шаг и укорачивает генерацию блока.
- Когда нужен `JointThreshold` с редактированием: без файла все его пороги правок равны нулю и `penalty_lambda` выключен.
- Когда модель требует иного размера блока, чем зашито в таблицу архитектур.
- Не задавать файл ради одного `block_size`, если размер из таблицы вас устраивает: переопределение потянет за собой и `--page-size`.
- Не полагаться на валидацию: опечатанный ключ будет молча проигнорирован, и вы получите поведение по умолчанию.

## Влияние на производительность и память

- VRAM: только косвенно, через `block_size` → `--page-size` → округление длин в KV-пуле.
- RAM хоста: не влияет.
- Время старта: файл открывается и парсится несколько раз, объем ничтожен.
- Latency: главный рычаг. Порог раскрытия напрямую определяет число шагов на блок: при агрессивном пороге блок разглаживается за единицы шагов, при консервативном — почти за `block_size`.
- Качество: снижение порога раскрывает менее уверенные позиции раньше, и они больше не пересматриваются (у `LowConfidence` правок нет). У `JointThreshold` компенсация есть, но она стоит дополнительных шагов из бюджета `max_post_edit_steps`.

## Взаимодействие с другими аргументами

- `--dllm-algorithm`: единственный флаг, при котором файл читается; он же определяет, какие ключи будут восприняты.
- `--page-size`: если в файле задан `block_size`, страница будет приравнена именно к нему.
- `--dllm-fdfo`: определяет, выполняется ли шаг алгоритма внутри одной итерации планировщика или один шаг на итерацию; у `JointThreshold` от этого зависит, используется ли общее батчевое состояние (`vectorized_decoding` + синхронная петля).
- `--config`: другой механизм (значения аргументов сервера), не путать.
- `--max-running-requests`: при незаданном значении конфиг диффузии подставляет `1`.

## Типовые проблемы и диагностика

- `FileNotFoundError` на старте — путь неверен либо файл недоступен процессу.
- `ImportError: Please install PyYAML to use YAML config files.` — в окружении нет PyYAML.
- `AttributeError: 'list' object has no attribute 'get'` — в файле список вместо отображения.
- Параметр задан, а поведение не изменилось — опечатка в имени ключа (валидации нет) либо ключ относится к другому алгоритму.
- `--page-size` в дампе не тот, что вы задавали — сработало переопределение `block_size` из файла.
- Что смотреть: дамп `server_args=` (там будет путь, но не содержимое) и warning `Setting page size to N for diffusion LLM inference`, по которому видно фактический размер блока.

## Примеры

Файл `/etc/sglang/dllm.yaml`:

```yaml
threshold: 0.9
```

```bash
python -m sglang.launch_server --model-path /models/LLaDA2.0-mini-preview --dllm-algorithm LowConfidence --dllm-algorithm-config /etc/sglang/dllm.yaml
```

```bash
python -m sglang.launch_server --model-path /models/LLaDA2.0-mini-preview --dllm-algorithm JointThreshold --dllm-algorithm-config /etc/sglang/dllm-joint.yaml --no-dllm-fdfo
```
