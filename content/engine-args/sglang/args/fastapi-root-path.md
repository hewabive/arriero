# --fastapi-root-path

## Кратко

`--fastapi-root-path` — это ровно параметр `root_path` uvicorn, ничего больше. SGLang сам значение не интерпретирует: во всем дереве `python/sglang/srt/` оно встречается четыре раза — объявление поля и три передачи в `uvicorn.run` / `uvicorn.Config`. Ни один обработчик, ни middleware, ни auth-слой его не читают.

Смысл параметра — сообщить приложению, под каким внешним префиксом оно видно, чтобы сгенерированные ссылки (OpenAPI-схема, `/docs`) указывали на правильный URL. Маршрутизацию входящих запросов он в SGLang не переписывает.

Ловушек две: при `--enable-http2` значение не доходит до Granian, а arriero про префикс не знает вообще.

## Оригинальная справка

```text
App is behind a path based routing proxy.
```

## Паспорт аргумента

- Флаги: `--fastapi-root-path`
- Группа: `serving`
- Тип значения: str
- Допустимые значения: `choices` нет; формат не проверяется — ни ведущий слэш, ни отсутствие завершающего никто не навязывает
- Значение по умолчанию: `""` (пустая строка), то есть префикса нет
- Эффективное значение: совпадает с заданным. `__post_init__` его не трогает, валидации нет. Фактически неприменимо в одном режиме: при `--enable-http2` ветка запуска Granian параметр `root_path` не передает
- Где объявлен: `ServerArgs.fastapi_root_path`, файл — `sglang/python/sglang/srt/server_args.py`
- Статус: обычный
- Этап применения: HTTP-слой, `_setup_and_run_http_server` — при создании uvicorn-сервера

## Что меняет в движке

На движок — ничего. Значение передается как `root_path=server_args.fastapi_root_path` ровно в трех местах `entrypoints/http_server.py`:

1. `uvicorn.Config(...)` в ветке `--enable-ssl-refresh`;
2. `uvicorn.run(app, ...)` в обычной одно-tokenizer'ной ветке;
3. `uvicorn.run("sglang.srt.entrypoints.http_server:app", ..., workers=N)` в ветке `--tokenizer-worker-num > 1`.

Ветка `_run_granian_server` (`--enable-http2`) не принимает такого параметра вовсе — сигнатура функции его не содержит.

Дальше значение живет уже внутри ASGI-стека: uvicorn кладет его в `scope["root_path"]`, а FastAPI использует при построении `servers` в OpenAPI-схеме и при генерации URL. Как именно префикс соотносится с сопоставлением маршрутов, зависит от версии пары uvicorn/starlette в вашем окружении; SGLang в это не вмешивается. Практическую проверку делайте на своей сборке:

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:30000/v1/models
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:30000/llm/v1/models
```

Это же касается и auth-слоя: исключение для health-проб в `decide_request_auth` сравнивает `request.url.path` буквально с префиксами `/health` и `/metrics`. Если при вашей версии стека путь в scope сохраняет внешний префикс, то `/llm/health` под это исключение не попадет и потребует ключ. Проверяется той же парой curl-запросов при заданном `--api-key`.

## Значения и формат

- Строка вида `/llm`. Ведущий слэш принято ставить — это соглашение ASGI, а не проверка SGLang.
- Пустая строка (значение по умолчанию) означает отсутствие префикса.
- Завершающий слэш лучше не ставить: он даст двойной слэш в сгенерированных URL.
- Валидации нет: любая строка будет принята и передана дальше как есть.

## Когда использовать

- Сервер стоит за обратным прокси, который отдает его по пути вроде `https://gateway.example/llm/`, **и** вам нужны корректные `/docs` и OpenAPI-схема. Для чистого проксирования `/v1/*` без документации параметр не обязателен.
- Не используйте при `--enable-http2` — значение просто не дойдет.
- Не используйте на инстансе, обслуживаемом менеджером arriero: манипулировать префиксом он не умеет (см. ниже).

## Влияние на производительность и память

Нулевое: строка, переданная в конфигурацию ASGI-сервера один раз при старте.

## Взаимодействие с другими аргументами

- `--enable-http2`: значение не передается в Granian, аргумент фактически перестает действовать.
- `--enable-ssl-refresh`: передается, ветка `uvicorn.Config` его учитывает.
- `--tokenizer-worker-num > 1`: передается в multi-worker `uvicorn.run`.
- `--api-key` / `--admin-api-key`: см. выше о буквальном сравнении путей `/health` и `/metrics` в `decide_request_auth`.
- `--host`, `--port`: на привязку сокета никак не влияет — это путь, а не адрес.

## Типовые проблемы и диагностика

- **Симптом:** префикс задан, а `/docs` за прокси все равно грузит ресурсы по неправильным путям. **Причина:** прокси снимает префикс, а приложение о нем не знает, либо наоборот. **Лечение:** согласовать: либо прокси снимает префикс и вы задаете `--fastapi-root-path`, либо прокси передает путь целиком и параметр не нужен.
- **Симптом:** префикс задан вместе с `--enable-http2`, и эффекта нет. **Причина:** параметр не передается в Granian. **Проверка:** grep по `root_path` в `entrypoints/http_server.py` показывает три вхождения, все в uvicorn-ветках.
- **Симптом:** при заданном `--api-key` health-проба под префиксом получает 401. **Причина:** исключение в `decide_request_auth` сравнивает путь буквально. **Проверка:** `curl -i http://127.0.0.1:30000/<префикс>/health` без заголовка. **Лечение:** направлять health-пробу на непрефиксованный адрес движка.
- **Симптом:** непонятно, применилось ли значение. **Проверка:** строка `server_args=` в логе старта показывает `fastapi_root_path='...'` — но она отражает поле датакласса, а не факт передачи в сервер; для Granian-ветки значение в дампе будет, а эффекта не будет.

## В arriero

Аргумент менеджером не поддерживается. Дескриптор движка `ktransformers` объявляет `apiPrefixArgKeys: []` (`packages/core/src/engine-descriptor.ts`), то есть список аргументов, из которых менеджер извлекает префикс пути, для этого движка пуст. Функция `instanceBaseUrl` (`apps/api/src/instances/endpoint.ts`) строит адрес как `http://<host>:<port>` без какого-либо суффикса.

Практически:

- health-проба `/health` и проба `/v1/models` пойдут по непрефиксованным путям;
- прокси менеджера тоже будет обращаться к `<base>/v1/...` без префикса.

Работать это будет ровно до тех пор, пока непрефиксованные пути остаются доступными — а они доступны, потому что `root_path` в ASGI задуман для случая, когда префикс снимает внешний прокси. Но полагаться на это в конфигурации arriero незачем: для инстанса kind `ktransformers` `--fastapi-root-path` не нужен, наружу инстанс отдает не он, а менеджер (`docs/SUBPATH_DEPLOY.md` — про subpath уже самого arriero).

## Примеры

```bash
python -m sglang.launch_server --model-path /models/Qwen3-30B-A3B --host 127.0.0.1 --port 30000 --fastapi-root-path /llm
```

```bash
curl -sS http://127.0.0.1:30000/openapi.json | python3 -c "import json,sys;print(json.load(sys.stdin).get('servers'))"
```
