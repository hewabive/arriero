## Negative finding

The public `kt-kernel==0.6.3.post1` wheel selected its advertised AVX2
extension on this host but `kt_kernel_ext.CPUInfer(1)` terminated with
`SIGILL`. Its AVX2-named shared object contains AVX-512 instructions, while
this host exposes AVX2 only.

Arriero environment validation and launch preflight now execute the same
minimal `CPUInfer(1)` smoke test. A package that imports successfully but
cannot construct the CPU backend is rejected before model launch.
